# Sprint 1 — Understand and document

## Goal

Know the codebase well enough to change it safely, and leave that knowledge in the repo.

## Scope

- Survey kernel, agent, host/protocol, both managers, frontend.
- `docs/wiki/`: developer notes plus one page per subsystem.
- Amend `AGENTS.md` so `docs/wiki/` and `Sprints/` are allowed doc locations.
- Create `dev`; write the six-sprint roadmap; plan sprint 2.

## Out of scope

Any change to code or behaviour.

## Acceptance

- A new contributor can find, from the wiki alone, where to add a game mode, a wire message and a manager endpoint.
- Baseline: the existing build and test gate passes untouched on this branch.
- PR merged into `dev`.
