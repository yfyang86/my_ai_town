# AI 小镇

> 对这个游戏感兴趣的话，欢迎加入 QQ 群 **130703560** 一起讨论。

一个由 AI 居民自己过日子的小镇。你可以在旁边观察，也可以用自己的化身走进去，和他们说话。

居民会安排日常、使用物品、结识邻居，并记住亲身经历。模型负责提出想法和行动，世界内核负责检查和执行；发生了什么，以世界里的实际结果为准。

#### 故事模式

上面建成的小镇打开的是故事模式。故事只说发生了什么、每个人想要什么；去哪里、找谁、说什么都由 AI 自己定，结局可以和提纲不一样。

| 环节 | 说明 |
| --- | --- |
| 节拍 | 到点对所有人宣布一件事，单独叮嘱有关的几个人；要紧的当面交锋开一场轮流说话的戏 |
| 里程碑 | 有的到点就算，有的要几个人凑到一处，有的由当事人自己宣布 |
| 旁观界面 | 顶上是故事名和此刻到了哪一幕，左边是角色，右边是时间线和里程碑，底下是戏里刚说的话 |

剧本里另带一本手写的「灯塔之约」：六个人、一天、一座要卖的老灯塔。

#### 第五版规则（可选）

故事模式可以开一套掷骰的规则，照 Dungeons & Dragons 第五版的 SRD 5.1 写成（署名见 `NOTICE`）。开了以后每个角色有一张角色卡——战士、游荡者、牧师、法师四个职业，一到三级——成不成说不准的事由世界掷 d20。不开的时候，故事模式和原来一字不差。

| 部分 | 说明 |
| --- | --- |
| 检定 | 剧本里写好的事（说动围观的人、看懂账、当面逼问）各有难度和几种试法，每人照自己的属性和技能加值掷；有优势和劣势、对抗、被动察觉，同伴可以帮一把 |
| 临场的事 | 角色想做剧本里没写的事（撬门、翻墙、认脚印），由一位模型主持人裁定用哪项属性和技能、多难；主持人只能从固定的单子里选，骰子是世界掷的，成败也由骰子定 |
| 动手 | 剧本里的遭遇战按先攻轮流出手：攻击、闪避、撤步、冲刺、帮同伴，走开会挨借机攻击；生命归零的人倒下掷死亡豁免，撑不过去的角色在世界里真的死去。角色之间动手走决斗，打到一方倒下为止，不死人 |
| 法术、休息和成长 | 牧师和法师有法术位和准备好的法术（火焰箭、魔法飞弹、治疗伤口、祝福术等十四个）；受了伤可以短休花生命骰，在床上睡够一觉算长休；打赢遭遇战、达成自己名下的里程碑得经验，够了升级 |
| 怎么开 | 「灯塔之约」的开局设置里「规则」一行选「第五版规则」；「写一个故事」时勾上「用第五版规则」，模型会连角色卡、检定和遭遇战一起排好，过目时能改能删 |
| 旁观界面 | 左边名字后面是职业和等级（鼠标停上去看整张角色卡），右边多了骰子记录和战况 |
| 要求 | 连着的模型要能按格式交动作；内置的小模型跟不上，请连一个模型服务再开 |

#### 剧本的规则可以改

「三体 · 执剑人之夜」的开局设置里多了收起来的「规则」。不动它就和原来一模一样。

| 可改项 | 内容 |
| --- | --- |
| 钟点 | 敲钟、演说、交接的时间 |
| 期限 | 说话、投票、按不按的期限 |
| 环节开关 | 罗辑先说的一句、选民表态、交接时的一句、水滴来袭、智子最后的话都能关；关掉水滴来袭，交接完这一局就结束，结局是「威慑延续」 |
| 人设 | 旁边的「人设」可以改这一局每位选手的名字、性格、处境和想要的东西，只管这一局 |

#### 剧本可以不显示

选择小镇页「剧本」旁边点「显示哪些」，不想看到的剧本勾掉；只是不列出来，开过的那一局还在。

#### 提示词可以调

首页和游戏里的「设定」多了「提示词」：模型写故事、写人物时照着的那段话，现在能自己调。所有小镇共用。

| 用法 | 说明 |
| --- | --- |
| 默认 | 随应用带的那一份。写故事的默认已经带着「讲究一点」：人物写具体的习惯和物件，各人的目标要相撞，节拍逼人当场做选择 |
| 风格模式 | 先挑一套风格（写故事有古龙式武侠、本格推理、温情日常、权谋群像、荒诞喜剧和通用的「讲究一点」；写人物有五套），再逐段改：身份、背景、文风、例子、不要、自查。只调味道，模型交回来的格式不变 |
| 专业模式 | 整份提示词自己写，连输出格式在内；占位符列在旁边，随时能恢复默认 |
| 试一试 · 比一比 | 贴一段故事或提纲（或一句话的人物描述），选两份提示词各跑一次，结果并排看；看中哪边点「就用这一份」 |

#### 记录可以下载

小镇一直在把发生过的事记下来，菜单里的「记录」能整份下载，世界开着或停着都行。

| 种类 | 内容 |
| --- | --- |
| 对话 | 私聊里的每一句、玩法里的发言（议事、演说……），带时刻、谁说的、对谁说的 |
| 想法 | 居民每次做决定时心里想的和来由 |
| 世界日志 | 走动、活动、检定、战斗这些发生过的事 |
| 模型轨迹 | 发给模型的请求、模型的回复、工具调用和结果；很大，默认不勾 |

格式三选一：JSON（一个文件，带小镇和条数）、JSONL（一行一条）、文字（给人读）。记录存在这个小镇自己的目录里（`transcript/`），删掉小镇时一起删。

#### 居民会做梦

居民睡够两个钟头醒来，会把睡前这段日子的记忆理一遍：

- 很久以前的琐碎见闻不再想起。
- 新经历够多时做一个梦，从里面想明白几件以后用得上的事（比如「食堂过了饭点就没饭了，得赶着点去」），放下几件用不上的，留下两三句梦。
- 点开居民，「记着的事」下面多了一栏「梦」。

#### 想起来的更对路

居民回想往事不再只按字面找：两个字的人名、地名也查得到，和眼前的人和事越相关、越新、越要紧的越先想起来。

#### 执剑人之夜

选择小镇页里新增第三个内置小镇「三体 · 执剑人之夜」：威慑纪元 62 年的海岸小镇，有联合国大厅、广场、引力波天线、智子茶室、公元纪念馆、墓园和集市。

**人物**（九个人按号码入住，各有自己的像素长相）：

| 号码 | 人物 | 身份 |
| --- | --- | --- |
| 1 号 | 罗辑 | 现任执剑人 |
| 2 号 | 程心 | 候选人 |
| 3 号 | 维德 | 候选人 |
| 4 号 | 智子 | 三体世界的代表，开着茶室 |
| 其余五位 | — | 选民，各有立场 |

**一天的流程**：

1. 白天各自活动、私下拉票。
2. 傍晚敲钟后到广场：罗辑先说一句，程心和维德演说，选民依次表态，然后投票；平票由现任执剑人指定。
3. 当选的人在联合国大厅地下交接。
4. 交接后水滴来袭，新执剑人十分钟里按或不按：按下是引力波广播，没按是威慑失败；最后智子对全镇说一段话。

**旁观界面与演出**：

- 顶上的横幅写着到了哪一步，水滴来袭时变成红色警报和倒计时。
- 左边是名单，底下的卡片放刚说的话和心里话，右边是票型、开关和结局。
- 天上一颗像素水滴飞向天线：按下了天线发出引力波、水滴掉头，没按就撞上天线。
- 投票时放决战曲，水滴来袭放「情况危急」。

**开局设置**：演说先后、白天 4、6 还是 8 小时。

#### 大逃杀只活一个

大逃杀荒岛开始分输赢：开局每人一张纸条写明规则，只有最后一个人能活着离开。

**潮水圈时间表**（四天收完五圈）：

| 时间 | 事件 |
| --- | --- |
| 第 2 天 | 一圈 |
| 第 3、4 天 | 上午、下午各一圈 |
| 第 4 天中午 | 最后一圈公布时船也来了，谁先登船谁走 |

#### 「对话」和动态贴边

- 狼人杀的议事、遗言、狼人频道，执剑人之夜的演说、表态，这些玩法里的发言都归进「对话」。
- 动态列表按天分段，一天只写一次「第 N 天」；说话和想法名字单独一行，带号码、场合或想法的来由，正文另起一段；世界里发生的事一行小字。
- 电脑上展开动态后可以点「贴左」「贴右」，动态贴着窗口边成从顶到底的一整列，地图让到旁边，座位、发言卡和化身面板跟着地图挪；拖边调宽，双击还原，下次打开还是这样摆。手机和平板不变。

#### 题面只写给模型看的东西

发给模型的请求清掉了空字段、长小数和程序编号，累积摘要写成人话；背包里一堆东西只列一个短编号，不再截断（大逃杀第三局急救包和竹筒水被截掉看不见）。在回声湾的副本上，每次请求里给程序看的字从 553 降到 0，村民照常做事。

#### 道具库

一件道具只占一行，只列最新一版，行尾写「镇上有 N 件」。自己做的道具能删：详情右下的红字「删除」，就地确认后删掉这件的所有版本；镇上已经摆着的、背包里的还在，说明和「复制并修改」照样能用。自带的删不了。

#### 修复

- 新放的道具跟前站不到时人会卡住、存档读不回来：现在放置时避开这种位置，站在走不通的地方也能先迈出去再找路。
- 录像里病人的身体只记变了的几项，一段不再涨到几十 MB。
- 建镇第 3 步的地点列表不再等小镇服务，连不上时说清楚原因。
- 大逃杀收局的公告不再重复名字、不再用「他」；开局布置的道具编号和调额度的回执对上了，从选小镇到「开始这一局」一路走通。

#### 狼人杀

选择小镇页里新增「月影村狼人杀」：雪山下的村子，有 1～12 号木屋、议事广场、老钟楼、老酒馆和狼嚎林，6～12 人（默认 9 人）。

**一局的流程**：

| 阶段 | 发生什么 |
| --- | --- |
| 白天 | 各过各的、私下串联；傍晚敲钟后到议事广场按座号轮流发言、一起投票，平票的两人各再说一句再投；被放逐的人留下遗言走出村子 |

## 怎么开始

第一次进入小镇，向导会带你选模型、邀请居民、填写世界观，然后开始运行。可以先用自带的小镇和默认居民。

### 观察

- 左键拖动平移、滚轮缩放；按住右键左右拖动环绕小镇，上下拖动调整俯角。点击「街景」或「俯视」恢复预设方向。
- 点居民，脚下会冒出「说话」「跟随」「附身」「资料」；鼠标在房子上停一下会掀开屋顶看屋里，点屋顶让它一直开着。
- 空格暂停或继续，没人走动或说话时会自动快进。
- 电脑上点左下角「全部动态」后可以点「贴左」「贴右」，动态贴着窗口边成从顶到底的一整列，地图让到旁边；拖那条边调宽，双击还原，下次打开还是这样摆。

### 化身

- 点底部正中的「进入化身」（手机点底部入口的「化身」）。
- 点地图走过去，点房子走进门；也可用 WASD 移动、按住 Shift 跑，E 互动，B 打开背包。
- 使用药箱、复苏石这类能给别人用的东西时，在背包里选对谁用。

### 化身神力

点地图左上角的「世界观」，在「规则」里打开后，化身可以复活、治愈、补满身边的人。按 F 或点操作条上的「神力」，也可以在死亡提示卡、村民脚下的按钮和角色卡上点，化身会自己走过去。在场的村民会看到是谁做的。默认关闭。

### 结伴同行与约定

- 和居民交谈时点「跟我来」「你带路」（操作条的「告辞」里也有），对方答应就一起走：你带路时步子放慢，他跟在身后；他带路时化身自动跟着走，自己走动就不再跟，操作条上能再打开「自动跟随」。
- 到了地方同行自动结束。交谈里也能约时间地点见面，到点前双方都会收到提醒。
- 居民之间同样会约着一起走、约见面，看得见谁往哪儿去了，到了地方会「查看四周」核实听来的说法。

### 道具

- 点底部正中的「道具」（手机点底部入口的「道具」）打开道具浮窗，先按地点看镇上有什么，点一件镜头飞过去看它在哪。
- 要放新东西，点地图上亮着的地方或地点头上的「往这里放」：拉近后亮格子能放，指到哪里绿框就落在哪里，放不了的地方会说为什么；点一下定下位置，再点浮窗里要放的东西，指着一件时绿框换成它的大小。
- 可以接着放、撤销刚放的，也能移除已有的。改道具、导出道具包在浮窗底下的「道具库」。

### 玩法

选择小镇页里的「大逃杀荒岛」「月影村狼人杀」和「三体 · 执剑人之夜」是带玩法的内置小镇：选中后在开局设置里挑人数和规则，点「开始这一局」。

| 玩法 | 规则要点 | 旁观时地图上画着 |
| --- | --- | --- |
| 大逃杀 | 潮水四天里收五圈、最后一圈公布时来船 | 潮水圈 |
| 狼人杀 | 法官主持白天发言投票、夜里各身份行动 | 座位、发言和票型 |
| 执剑人之夜 | 威慑纪元 62 年选新执剑人的一天：傍晚罗辑说一句、程心和维德演说、选民表态后投票，19:00 交接，交接后水滴来袭，新执剑人十分钟里按或不按 | 名单、演说、票型、倒计时和天上的水滴 |

### 设置

- 这一局的世界观、规则（村民初来乍到、村民生理、化身神力）和录像开关点地图左上角的「世界观」修改，重置世界也在那里。
- 村民的人设、长相和用哪个模型在他的角色卡里改：点「资料」打开角色卡，翻到「人设」「长相」「模型」页签，村民页每行的「档案」也直达这里。
- 其余入口在右上角的「菜单」里（手机在底部入口最右边，电脑上也可以按 Esc 打开）：居民、设定、消耗、帮助、选择小镇和音乐、音效开关。
- 「设定」管模型服务、默认模型、花费上限、声音和显示；「设定 → 显示」可以改画质、失焦模糊、地图俯角和文字大小。
- 点时钟牌上的天气图可以切换天气。

### 保存

在「菜单」里点「选择小镇」时保存并关闭当前小镇。个人地图、居民、记忆和日志保存在本机用户目录，不会写回仓库。

## 从源码启动

### Windows 启动器

Windows 可运行 `node scripts/windows/build-local-launcher.mjs`，在根目录生成 `AI小镇启动.exe`。双击会启动本地 Ollama 和小镇服务，再打开浏览器。沿用 `.local/run-data` 中的存档；打开的是选镇页，进入小镇后再手动开始运行。重复双击会复用服务。

启动器需要保留在项目根目录，依赖本机已安装的 Node.js、已编译的 Rust 内核和现有模型，不是可单独拷走的安装包；生成的 EXE 不随源码入库。配置方法见[Windows 本地启动器](docs/README.md#windows-本地启动器)。

### macOS 步骤

先安装 Node.js（见 `.nvmrc`，最低 22.18）、Corepack 和 Rust 工具链 1.88.0。在 macOS 上按以下步骤运行：

```sh
git clone https://github.com/mewamew/my_ai_town.git
cd my_ai_town
corepack pnpm install --frozen-lockfile
cargo +1.88.0 build --locked -p host --bins
corepack pnpm build
corepack pnpm preview
```

打开 `http://127.0.0.1:5174`。

### 内置模型（可选）

源码仓库不包含内置模型的推理程序和权重。要在 Apple 芯片的 Mac 上使用本地模型，先准备 CMake 和 Xcode 命令行工具，再运行：

```sh
node scripts/builtin-model/build.mjs
```

这会下载固定版本的 llama.cpp 并编译推理程序。重启管理服务后，到「设定 → 内置模型」下载模型文件（约 529 MB）；下载完成后，村民决策可在本地运行。仅运行上面的前端与 Rust 构建，不会自动编译推理程序。

也可以在游戏里配置自己的在线模型地址和 API 密钥。在线调用的费用由服务商收取；居民越多、运行越久，请求通常越多。请先从少量居民开始。

开发模式、平台打包和检查命令见[开发入口](docs/README.md)。
